# La collection spoliée de Raoul et Yvonne Meyer

Site documentaire consacré à la spoliation, en 1941, de la collection de peintures de
Raoul et Yvonne Meyer, et au sort de **cinq tableaux jamais localisés à ce jour** :
un Bonnard, un Marquet, un Modigliani/Soutine, un Renoir et un Pissarro.

Le site est entièrement en français.

## Voir le site sur votre ordinateur

- **Mac** : double-cliquez sur `demarrer-le-site.command`
- **Windows** : double-cliquez sur `demarrer-le-site.bat`
- **Linux** : exécutez `./demarrer-le-site.sh`

Le site s'ouvre alors à l'adresse <http://localhost:8000>.

## Organisation des fichiers

```
contenu/     Tous les textes, légendes et crédits    ← c'est ici que l'on travaille
images/      Tous les visuels                        ← c'est ici que l'on dépose les images
index.html   Page d'accueil                          ← mise en page, ne pas modifier
tableaux/    Les cinq pages de tableaux              ← mise en page, ne pas modifier
demarches/   Les trois pages sur les réclamations    ← mise en page, ne pas modifier
assets/      Feuille de style et moteur d'affichage  ← mise en page, ne pas modifier
```

## Nature technique

Site **statique** : HTML, CSS et JavaScript standards, sans générateur de site, sans
dépendance extérieure, sans étape de fabrication. Il peut être hébergé gratuitement
sur GitHub Pages ou par glisser-déposer sur Netlify Drop.
